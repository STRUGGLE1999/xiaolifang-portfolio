学术成果与发明专利

Research, Patents & Credentials · 国际论文 · 国家发明专利 · 资质认证

以下为具有国家法律效力与国际学术同行评审（Peer-Reviewed）认可的学术研究资产与权威资质证书：

国际学术论文 (Academic Publications)

《CMCLNet: Cross-Modality Attention Fusion and Cross-Level Feature Interaction Network for RGB-D Salient Object Detection》 第一作者 (First Author 🌟) IEEE CCIS 2023
2023年

发表于 IEEE 国际学术会议（CCIS）。针对 RGB-D 显著性目标检测中深度传感器物理噪点与低光照失效难题，创新提出跨模态注意力融合（CMAF）与跨层特征交互（CLFI）架构，在 7 大国际公开基准数据集上超越主流 SOTA 算法。

《FGNet: Fixation guidance network for salient object detection》 SCI 期刊核心作者 已被引 11 次
2023年

发表于 Springer 旗下的 SCI 核心期刊《Neural Computing and Applications》(NCAA)。借鉴人类生物视觉注视点（Fixation Points）引导机制构建双支路网络，显著提高杂乱复杂背景下物体轮廓提取的召回率与鲁棒性。

《A Virtual Body Try-on Model Based on Edge Detection Algorithm》 IEEE 国际会议 姿态估计
2022年

发表于 IEEE 国际学术会议。聚焦边缘轮廓检测与人体 2D 姿态关键点估计，结合生成对抗网络（GAN）实现高保真度的虚拟试衣与图像融合生成。

国家发明专利 (Invention Patents)

《基于多智能体协同的检索生成方法、系统、终端及介质》 国家知识产权局已授权 ZL 2025 1 1242726.0
2025年1月

国家知识产权局正式授权发明专利（专利号：ZL 2025 1 1242726.0，核心发明人）。针对政企复杂长文档知识库问答痛点，提出由策略路由 Agent、跨跳图谱实体对齐与对抗自编码器去噪构成的多智能体协同框架，从底层消除 RAG 检索退化与生成幻觉。

《一种检测模型训练方法、目标检测方法和相关设备》 初审合格实审中 202511080160.6
2025年

国家发明专利申请号：202511080160.6。提出 HMPAC 混合多级原型注意力校准网络，解决复杂动态工业视频场景中微小目标与密集重叠物体的检测漏检难题。
